# Spotify Track Popularity Prediction

This project uses machine learning models to predict Spotify track popularity based on audio and metadata features.

## Models Used
- Linear Regression
- Ridge Regression
- Random Forest
- XGBoost
- LightGBM

## Evaluation Metrics
- RMSE
- MAE
- R² Score

## Files Included
- Code for preprocessing, training, and evaluation
- Figures showing analysis and results
- Tables of model performance

## Key Insight
Tree-based ensemble models outperform linear models in predicting Spotify track popularity.

## Dataset
Spotify Tracks Dataset (audio features + metadata)
